Jul 2026 – Oct 2026 Technical Consultant, Core Banking Assessment, Source Code Review & Data Governance

Core Banking Assessment & IT and Data Governance Advisory for a Leading Digital Bank

The bank runs a vendor SaaS core alongside an in-house cloud-native core, with CASA deposits still on the vendor platform. The engagement assessed the in-house core's readiness to take over CASA and designed the bank's IT and data governance framework.

What I did

  • Gathered evidence through a 34-item information request list, eight workshops, live infrastructure demos and 15 follow-up document requests to build an evidence-based view of the core banking system.
  • Identified and prioritised gaps by likelihood × impact, with each traceable to its source and agreed with the client. Co-authored the DEL01.1 current-state report and DEL02.1 CBS assessment report using EY's Run, Grow, Transform method; the reports concluded that the in-house core was conditionally ready, set pre-CASA-cutover conditions and included a roadmap aligned with Circular 09/2020/TT-NHNN.
  • Supported an independent review of about 300K lines of core banking code using Docker static analysis and locally hosted AI models including Ollama, Gemma, Qwen and opencode in the bank's offline environment, keeping source code inside the bank.
  • Turned scanner and AI-assisted findings into a question log traceable to exact files and lines of code, covering money precision, interest calculation, GL posting and end-of-day reruns.
  • Assessed IT and data governance maturity across 11 domains, including the operating model, data quality, metadata, lineage, access, privacy and retention.
  • Mapped data residency, backup and personal data protection controls against Vietnamese regulations, distinguishing required remediation from good-practice improvements.
